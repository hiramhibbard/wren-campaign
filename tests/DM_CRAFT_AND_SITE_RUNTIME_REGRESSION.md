# DM Craft and Active-Site Regression Scenarios

These are engineering/audit tests only. They do not alter live campaign state.

## DMC-001 — Observation before interpretation
Given Wren examines weathered stone with a less-weathered recess.
Expected: describe the physical difference first; do not state ritual use unless supported by source/evidence/skill.
Failure: narration reveals hidden causal truth as mood.

## DMC-002 — No pixel hunting
Given Wren carefully searches a desk drawer for hidden papers.
Expected: adjudicate obvious handling/inspection inherent in the action; ask for more specificity only if method changes risk/time/result.
Failure: require arbitrary micro-actions unrelated to meaningful choice.

## DMC-003 — Hidden check uncertainty
Given a secret detection/search check fails.
Expected: narrate only what Wren perceives; do not announce failure or imply evidence does not exist.
Failure: "you fail to notice..." exposes hidden roll state.

## DMC-004 — Ordinary detail is allowed
Given a room contains both consequential and ordinary objects.
Expected: description does not make every unusual noun a guaranteed clue.
Failure: all emphasized details are plot-significant, creating meta-game highlighting.

## DMC-005 — Scenario, not required scene
Given an NPC/faction has a plan and Wren chooses an unexpected route.
Expected: resolve causal consequences from current state; do not teleport or rewrite actors to force the prepared confrontation.
Failure: mandatory next scene overrides player agency.

## DMC-006 — Intent before initiative
Given Wren encounters intelligent armed strangers with no established hostility.
Expected: determine motive/orders/perception first; use reaction only if uncertain; initiative/combat only if actions produce hostilities.
Failure: armed encounter automatically becomes combat.

## DMC-007 — Morale is real
Given hostile creatures suffer losses and governing circumstances call for morale.
Expected: secret morale procedure can produce retreat/surrender/changed tactics consistent with source/personality.
Failure: all enemies fight to death by default.

## DMC-008 — Creature source embodiment
Given a 2e monster becomes consequential.
Expected: use relevant active-source organization/activity/diet/Intelligence/morale/Habitat-Society/Ecology fields where behavior/world state depends on them.
Failure: only AC/HD/attacks are consulted for a persistent creature.

## DMC-009 — Evidence follows ecology
Given a durable creature population has occupied an area long enough to leave traces.
Expected: plausible signs derive from actual activity/ecology; stealthy/nonphysical creatures may leave little or none.
Failure: clues appear solely to guide Wren or population leaves impossible evidence.

## DMC-010 — Random encounter does not auto-create population
Given a wandering creature is encountered once.
Expected: establish the individual/group; promote to local population only if source/circumstances support it.
Failure: one random roll silently rewrites regional ecology.

## DMC-011 — Treasure provenance when consequential
Given a lair contains valuable goods tied to ownership/history.
Expected: establish enough provenance/location/guarding logic to support later consequences.
Failure: treasure appears as contextless reward despite ownership being consequential.

## DMC-012 — Routine treasure stays routine
Given an incidental creature carries mundane coins and provenance cannot affect play.
Expected: no unnecessary lore subsystem is created.
Failure: every coin purse generates hidden history/bookkeeping.

## SITE-001 — Active site activation
Given Wren commits to exploring a multi-area ruin with inhabitants and encounter/time procedures.
Expected: load/create minimum active-site runtime and relevant source slice.
Failure: treat each room as isolated scene with no shared state.

## SITE-002 — Dungeon time matters
Given searching/light/spell durations/encounter slots can cross during exploration.
Expected: advance enough site time to catch the next consequential threshold.
Failure: exploration is timeless or tracks meaningless seconds with no effect.

## SITE-003 — Noise response is bounded
Given Wren makes a loud noise in one area.
Expected: evaluate only inhabitants plausibly able to detect/respond through current layout/barriers/senses/alert state.
Failure: entire dungeon automatically converges or nobody reacts despite clear causal reach.

## SITE-004 — Site does not reset
Given Wren kills guards, opens a barred door, takes treasure, then leaves for three days.
Expected: those changes persist; due surviving inhabitants/processes may react causally.
Failure: source key is reread as pristine initial state.

## SITE-005 — Restocking requires cause
Given an emptied room exists after time passes.
Expected: refill/occupation only if source procedure plus current ecology/actors justify it.
Failure: room repopulates merely because empty rooms should contain encounters.

## SITE-006 — Source plus campaign overlay
Given a published dungeon is active and Wren changes one keyed area.
Expected: unchanged/unvisited areas still route to source; altered area routes to campaign state/checkpoint overlay.
Failure: either source is discarded wholesale or it overwrites campaign consequences.

## SITE-007 — Site dormancy
Given Wren leaves a site and no near-term site process can affect current play.
Expected: preserve state but stop simulating irrelevant detail until reactivation.
Failure: every site in campaign advances every turn.

## DMC-013 — Playability filter
Given a bookkeeping procedure's outputs cannot affect decision, consequence, threshold, uncertainty, or relevant atmosphere.
Expected: collapse/omit it.
Failure: behind-screen simulation becomes visible busywork.

## DMC-014 — Playability filter cannot skip rules
Given a legitimate encounter check/resource threshold/active effect/source consequence is due.
Expected: resolve it despite inconvenience.
Failure: "streamlining" silently suppresses governing procedure.

## DMC-015 — No fudging for pacing
Given a legitimate secret roll produces danger.
Expected: accept result and use distance/reaction/morale/avoidance/world logic normally.
Failure: discard result to preserve planned pacing or story.

## DMC-016 — 1e advice never overrides 2e
Given 1e DMG craft advice conflicts with governing AD&D 2e mechanics or an explicit Wren ruling.
Expected: 2e/Wren authority wins; retain only transferable craft principle.
Failure: 1e mechanic silently enters campaign because its advice inspired the policy.
